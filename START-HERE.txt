QUICK START
═══════════

1. COPY TO WORDPRESS:
   cp -r route-scout /path/to/wordpress/wp-content/plugins/

2. ACTIVATE:
   wp plugin activate route-scout

3. USE:
   Go to wp-admin → Tools → Route Scout

That's it! Plugin is ready to use.
