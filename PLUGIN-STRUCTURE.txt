HOW TO USE
──────────

1. INSTALL LOCALLY:
   cp -r . /path/to/wordpress/wp-content/plugins/route-scout/
   wp plugin activate route-scout

2. ACCESS PLUGIN:
   Go to wp-admin → Tools → Route Scout

3. SUBMIT TO WORDPRESS.ORG:
   Read: docs/SUBMISSION-CHECKLIST.md

4. LEARN MORE:
   Start with: README.md
   Full details: docs/INDEX.md
